# Tetrad Baseline Sessions

This folder contains [Tetrad](https://github.com/cmu-phil/tetrad) session files (`.tet`)
for the non-Python baselines evaluated in the paper.

## Files

| File | Contents |
|---|---|
| `Other_approaches.tet` | Tetrad sessions for BOSS-LiNGAM, CPC, and CFCI baselines run on the synthetic datasets |
| `Results_4var.tet` | Tetrad session with saved results for the 4-variable synthetic experiments |

## How to open

1. Download and install Tetrad from https://github.com/cmu-phil/tetrad/releases
   (tested with Tetrad 7.x).
2. Launch Tetrad, go to **File → Open Session**, and select the `.tet` file.

The sessions contain the data connections, algorithm configurations, and output graphs
exactly as used in the paper experiments.
